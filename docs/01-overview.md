# Обзор проекта nova-ui

**nova-ui** — это фреймворк веб-интерфейсов для SS14 (Space Station 14), построенный на Svelte 5, TypeScript и Vite 7. Проект предоставляет систему модульных HTML/CSS/JS-оверлеев, которые отображаются поверх игрового клиента SS14 через встроенный браузерный движок (CEF/WebView).

## Архитектура

```
┌─────────────────────────────────────────────────┐
│                 Игровой клиент SS14              │
│  ┌─────────────────────────────────────────────┐│
│  │            NovaBridge (ev:// протокол)       ││
│  │  ← CustomEvent / hidden iframe →            ││
│  └─────────────────────────────────────────────┘│
│  ┌─────────────────────────────────────────────┐│
│  │         Веб-интерфейс (nova-ui)             ││
│  │  ┌──────────┐ ┌──────────┐ ┌──────────┐    ││
│  │  │ Модуль A  │ │ Модуль B  │ │ Модуль C  │  ││
│  │  └──────────┘ └──────────┘ └──────────┘    ││
│  └─────────────────────────────────────────────┘│
└─────────────────────────────────────────────────┘
```

## Ключевые возможности

- **Модульная система** — интерфейсы подключаются как независимые HTML-страницы
- **Автосканирование** — все модули в `src/interfaces/` автоматически обнаруживаются и регистрируются
- **NovaBridge** — двунаправленный протокол связи с нативным хостом
- **Терминальный стиль** — моноширинный дизайн с зелёным акцентом в стиле ретро-терминалов
- **Оптимизация под SS14** — сборка в `../Resources/dist` с агрессивной минификацией
- **Поддержка чанкования** — большие сообщения автоматически разбиваются на фрагменты
